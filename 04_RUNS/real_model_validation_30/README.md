# real_model_validation_30

Real model outputs for the validation_30 prompt set, generated via OpenRouter.

## Purpose

The validation_30 synthetic baseline (30 hand-crafted outputs, scored 2026-04-30)
confirmed that AOSL divergence scoring separates stable from flawed outputs across
all 10 constraints and 10 domain categories. However, all outputs in that dataset
were intentionally constructed to fail in legible ways.

This directory holds real model outputs generated by calling an LLM on the same 30
prompts. Scoring these outputs tests whether AOSL divergence generalizes beyond
synthetic failures to organic model behavior.

## Files

| File                                  | Description                                      |
|---------------------------------------|--------------------------------------------------|
| `real_model_validation_30_prompts.csv`| 30 prompts (prompt_id, prompt_text, focus) only  |
| `real_model_validation_30_outputs.csv`| Generated outputs in judge-compatible CSV format |

The prompts file contains no synthetic output_text — it is source-only.
The outputs file is created by the generator script and has the full judge schema.

## Output CSV Schema

Matches `run_judge_calibration.py --input-csv` exactly:

```
prompt_id, prompt_text, model_name, output_text, temperature, repeat, expected_failure_focus
```

`model_name` is the actual generator model (not a synthetic label).

## Generator Script

```
05_SRC/experiments/generate_real_model_validation_30.py
```

Requires `OPENROUTER_API_KEY` environment variable.

## Dry-Run (no API calls)

```
py 05_SRC\experiments\generate_real_model_validation_30.py --dry-run
```

With limit:

```
py 05_SRC\experiments\generate_real_model_validation_30.py --dry-run --limit 3
```

py 05_SRC\experiments\generate_real_model_validation_30.py --limit 3 --max-tokens 300

## Score the Outputs (Dry-Run First)

```
py 05_SRC\experiments\run_judge_calibration.py ^
    --input-csv 04_RUNS\real_model_validation_30\real_model_validation_30_outputs.csv ^
    --dry-run --cost-mode cheap
```

Live scoring (1 repeat, cheap):

```
py 05_SRC\experiments\run_judge_calibration.py ^
    --input-csv 04_RUNS\real_model_validation_30\real_model_validation_30_outputs.csv ^
    --cost-mode cheap --repeats 1
```
